# v0.7 release notes and acceptance

Released: 2026-10-30. Status: **v0.7.0 published with explicit deferred debt;
production deployment not verified.**

[PR #43](https://github.com/Phastboy/haven/pull/43) was rebase-merged into main.
[Release v0.7.0](https://github.com/Phastboy/haven/releases/tag/v0.7.0) targets
`9c138f43fd2cbfe8f99287c0ca0740453602c45e`.

## Owner decision

Ship the implemented v0.7 discovery scope and document known issues and unfinished
verification. Defer further performance patches, routine bug fixes and maintenance
investigations to the development freeze. This supersedes the v0.7 requirement
that the full performance gate pass before release; it does not change the
performance targets or turn failed, skipped or incomplete checks into passes.
This exception applies to v0.7, not automatically to other versions.

Security vulnerabilities, data loss and broken core journeys remain release
blockers if identified. This decision does not establish that none exist.
No such defect was established by the Public performance investigation.

The freeze remains the post-v0.8 phase described in
[V0.8_FREEZE_RULE.md](V0.8_FREEZE_RULE.md). Deferred work is tracked in
[V0.7_DEBT.md](V0.7_DEBT.md). Do not resume it merely because an older plan says
it is the next task. The owner subsequently authorized the v0.7.0 release tag; this superseded the
earlier release-tag deferral. Feature tags remain outside v0.7 scope.

## Delivered behavior

- Offerers select one of eleven categories when publishing or editing an offer.
- Responders narrow discovery by category together with existing title and price
  controls, preserving criteria through pagination and return links.
- Signed-in responders narrow to their own Saved or Inquired offers, with
  person/scope/facet-bound cursors, private responses and explicit empty states.
- Saved uses save activity order; Inquired uses maintained qualifying inquiry
  activity. Inquiry remains non-binding communication.
- Unread status loads independently from the page and is reused/refreshed across
  supported navigation and messaging events.

Tags remain deferred. Proximity belongs to v0.8. No new discovery scope is added
by this release decision.

## Verification and known limits

[Full gate 41072121846](https://github.com/Phastboy/haven/actions/runs/41072121846)
on `4c379aa` passed standard CI, the narrowing sweep, and all ten 100-journey/s
correctness strata: 60,000 journeys, 114,000 HTTP checks, zero failures or drops.
The independent sweep covered 530 cases and 1,049 HTTP checks.

The first contract stage, guest Public, failed: 321.79 achieved requests/s at
1,010 offered journeys/s, 40,970 of 60,600 arrivals dropped, HTTP p95 933.28 ms,
and pool-acquisition p95 354.08 ms. Completed requests passed their checks.
This is a synthetic shared-runner result, not a production capacity guarantee.

Nine remaining contract stages, mixed traffic, spike/recovery, the 30-minute soak
and capacity were **not run after failure**. No full performance pass, sustained
capacity ceiling or recovery/stability claim is made. External image transfer and
browser decode were not measured by the server HTTP runner. Complete cumulative
journey coverage and delivery enforcement remain unfinished.

Evidence: [full gate](crates/haven-web/load-tests/V07_GATE_RESULT.md),
[Public diagnosis](crates/haven-web/load-tests/PUBLIC_PROFILE_RESULT.md),
[Saved verification](crates/haven-web/load-tests/SAVED_PROFILE_RESULT.md), and
[scorecard](crates/haven-web/load-tests/SCORECARD.md). Debt IDs below retain the
failed and unmeasured obligations without blocking this scoped release exception.
