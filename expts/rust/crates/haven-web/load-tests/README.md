# Haven Rust Load Tests

This directory contains the load testing suite for the Rust implementation of Haven.

## Structure
- `k6/scenarios/`: Contains the individual k6 load testing scenarios (`01-smoke`, `02-steady-state`, etc.).
- `k6/lib/`: Common libraries and configurations for the scenarios.
- `monitor/`: Scripts to monitor system resources (CPU, Memory, Network) during the load tests.
- `data/`: Contains the seeded sessions (`sessions.json`) generated by `load-test-support`.
- `run-all.sh`: Orchestrator script to run the full suite and capture results.
- `PERFORMANCE_CONTRACT.md`: The defined SLAs and test targets.
- `SCORECARD.md`: Results from runs.

## Running Tests
To run the full suite:
```bash
./run-all.sh
```

To run a specific scenario:
```bash
SKIP_STEADY_STATE=1 SKIP_CAPACITY=1 SKIP_AUTHORIZATION=1 ./run-all.sh
```
