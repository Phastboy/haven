## Investigation stopping record

The completed Saved investigation stays closed. The accepted baseline already
contains its verified fix. Do not restart discarded Saved-status experiments.

Public JIT comparison: [CI 41078987201](https://github.com/Phastboy/haven/actions/runs/41078987201),
`391d0f4`. All captured statement JIT counters were zero; disabling JIT did not
clear contract load. About 98.6% of captured execution time under load belonged
to category/currency/price-filtered Public first/later statements.

Actual plans: [CI 41084281841](https://github.com/Phastboy/haven/actions/runs/41084281841),
`e38a9a9`. Free-price plans scan/sort before LIMIT (21–22 ms isolated); controls
use ordered index scans (0.6–0.8 ms). Maker lookup executes only 21 times in those
plans; excessive maker-join work was not established.

Rejected candidate: [CI 41086635067](https://github.com/Phastboy/haven/actions/runs/41086635067),
`ada6524`. Changing a zero upper bound to equality passed all 530 oracle cases /
1,049 HTTP checks, but retained parallel scans/sorts and failed contract load:
26,977/60,600 completed, 33,623 dropped, HTTP p95 666.02 ms. CI success means the
diagnostic completed; it does not mean the workload passed. Keep this candidate
out of v0.7; do not treat its different run timing as a proven improvement.
No subsequent index/statistics probe was dispatched.

Retained evidence is in `crates/haven-web/load-tests/evidence/41072121846`,
`41078987201`, `41084281841` and `41086635067` (relative to that evidence directory).
GitHub artifact retention is seven days; repository summaries and plans are the
durable record. Private sessions and fixture credentials are excluded.
