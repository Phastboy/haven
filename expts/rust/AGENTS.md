# Project records

Read the repository-root `ROADMAP.md` and `docs/JOURNEY.md` for product scope.
For v0.7 release status and accepted limitations, use `V0.7_RELEASE.md` and
`V0.7_DEBT.md`. Performance evidence lives in `crates/haven-web/load-tests/`.

Further performance patches, routine bug fixes and maintenance investigations
are deferred to the development freeze under the owner's release decision.
Historical investigation logs do not authorize resuming that work. Security,
data loss and broken core journeys retain immediate triage.
